  <action>
    **Bagian 1 — src/index.css (spinner removal):**

    Tambahkan di dalam `@layer base` (setelah rules base yang sudah ada, sebelum @layer components):

    ```css
    /* Hilangkan native spinner arrow di input type=number */
    input[type="number"]::-webkit-inner-spin-button,
    input[type="number"]::-webkit-outer-spin-button {
      -webkit-appearance: none;
      margin: 0;
    }
    input[type="number"] {
      -moz-appearance: textfield;
      appearance: textfield;
    }
    ```

    Rules ini menghapus native chrome:
    - Webkit (Chrome/Safari/Edge): `-webkit-appearance: none` pada spin buttons
    - Firefox: `-moz-appearance: textfield` pada input
    - Standard fallback: `appearance: textfield`

    **Bagian 2 — src/App.jsx (scroll wheel disable):**

    1. Tambahkan import: `import { useEffect } from 'react'`

    2. Di dalam function `AppContent()`, di sebelum return, tambahkan useEffect:

    ```jsx
    useEffect(() => {
      const handleWheel = (e) => {
        const el = document.activeElement
        if (el && el.tagName === 'INPUT' && el.type === 'number') {
          el.blur()
        }
      }
      document.addEventListener('wheel', handleWheel, { passive: true })
      return () => document.removeEventListener('wheel', handleWheel)
    }, [])
    ```

    **Kenapa `el.blur()` bukan `e.preventDefault()`:**
    - `preventDefault` butuh non-passive listener yang block scrolling → bad UX (page tidak bisa scroll)
    - `blur()` defocus input sehingga scroll wheel tidak lagi mengubah value, tapi user tetap bisa scroll page
    - Passive listener = zero performance impact

    **Yang HARUS dihindari:**
    - Jangan ubah JSX structure App.jsx
    - Jangan modify Router / Routes / Provider tree
    - Jangan tambah dependency baru (react-use, dsb)
    - Jangan bikin custom hook file baru — inline useEffect cukup untuk quick-fix
