<objective>
## Goal
Tambahkan tombol "Export PDF" di halaman Products yang men-download tabel daftar produk (Nama Produk, HPP, Harga Jual, Margin %) sebagai file PDF bersih siap print — langsung download tanpa preview.

## Purpose
Pengguna ReKal perlu menyerahkan atau menyimpan data HPP dalam format dokumen. PDF yang dihasilkan harus bisa dibagikan ke klien/supplier (teks selectable, bukan gambar), dan print-friendly (background putih, bukan dark Framer canvas).

## Output
- `src/components/products-pdf-template.jsx` — dokumen PDF React component
- `src/pages/Products.jsx` — tombol export ditambah di header
- `vite.config.js` — optimizeDeps untuk @react-pdf/renderer
</objective>

<task type="auto">
  <name>Task 2: Buat komponen PDF template daftar produk</name>
  <files>src/components/products-pdf-template.jsx</files>
  <action>
    Buat file `src/components/products-pdf-template.jsx`.

    Komponen menerima prop: `products` (array) dan `exportDate` (string, format "DD MMMM YYYY").

    Struktur PDF:
    - **Page**: A4, portrait, padding 40pt semua sisi, background putih
    - **Header section**:
      - Judul bold besar: "ReKal — Daftar Produk HPP"
      - Subtitle kecil di bawah: "Diekspor pada: {exportDate}"
      - Separator line tipis (border-bottom)
    - **Tabel**:
      - Header row: abu gelap bg (#1a1a1a), teks putih, bold
      - Kolom: No | Nama Produk | HPP | Harga Jual | Margin %
      - Lebar kolom (persentase dari page width):
        - No: 8%
        - Nama Produk: 40%
        - HPP: 20%
        - Harga Jual: 20%
        - Margin %: 12%
      - Data rows: alternating white (#FFFFFF) dan light gray (#F5F5F5) untuk readability
      - Teks data: hitam (#111111), font size 10
      - Align: No (center), Nama Produk (left), HPP (right), Harga Jual (right), Margin % (center)
    - **Footer**: nomor halaman kanan bawah ("Halaman {n}")

    Kalkulasi margin: `Math.round(((hargaJual - hpp) / hpp) * 100)` → tampilkan sebagai "{n}%" — tampilkan "–" jika hpp = 0 atau harga jual = 0.

    Format rupiah: import `formatRupiah` dari `../utils/formatters` — gunakan langsung.

    Font: gunakan default font @react-pdf/renderer (Helvetica). Tidak perlu register custom font.

    Gunakan `StyleSheet.create()` dari `@react-pdf/renderer` untuk semua style. Tidak ada Tailwind classes — @react-pdf/renderer tidak support Tailwind.

    Export komponen sebagai named export: `export { ProductsPdfDocument }`.
  </action>
  <verify>
    Import komponen di browser console tanpa error.
    Secara visual (dari kode): tabel punya 5 kolom dengan header abu gelap dan data rows alternating.
  </verify>
  <done>AC-3 satisfied: template berisi header, tabel 5 kolom, footer nomor halaman</done>
</task>

<task type="auto">
  <name>Task 3: Integrasikan tombol Export PDF di Products.jsx</name>
  <files>src/pages/Products.jsx</files>
  <action>
    **[Lihat output Stitch untuk styling tombol sebelum implementasi]**

    1. Import di atas file:
       ```jsx
       import { PDFDownloadLink } from '@react-pdf/renderer'
       import { ProductsPdfDocument } from '../components/products-pdf-template'
       import { Download } from 'lucide-react'
       import { format } from 'date-fns'
       ```

    2. Buat helper di dalam komponen untuk nama file dan tanggal:
       ```jsx
       const exportDate = format(new Date(), 'dd MMMM yyyy')
       const exportFilename = `rekal-daftar-produk-${format(new Date(), 'yyyy-MM-dd')}.pdf`
       ```

    3. Ubah header section dari:
       ```jsx
       <div className="page-header">
         <h1 className="page-title">Produk</h1>
         <p className="page-subtitle">Kelola produk dan hitung HPP</p>
       </div>
       ```
       menjadi:
       ```jsx
       <div className="page-header flex items-start justify-between gap-3">
         <div>
           <h1 className="page-title">Produk</h1>
           <p className="page-subtitle">Kelola produk dan hitung HPP</p>
         </div>
         {filteredProducts.length > 0 && (
           <PDFDownloadLink
             document={<ProductsPdfDocument products={filteredProducts} exportDate={exportDate} />}
             fileName={exportFilename}
             className="flex-shrink-0"
           >
             {({ loading: pdfLoading }) => (
               <button
                 disabled={pdfLoading}
                 className="btn-secondary flex items-center gap-2 disabled:opacity-50 disabled:cursor-not-allowed"
               >
                 <Download className="w-4 h-4" />
                 <span className="hidden sm:inline">Export PDF</span>
               </button>
             )}
           </PDFDownloadLink>
         )}
       </div>
       ```

    4. Tombol menggunakan `filteredProducts` — jika user sedang search, export hanya hasil filter tersebut.
    
    Perhatikan:
    - `PDFDownloadLink` merender sebagai `<a>` tag — jangan nest `<a>` di dalamnya
    - `pdfLoading` adalah state internal @react-pdf/renderer (generating) — beda dari `loading.products`
    - `btn-secondary` adalah class Framer design system yang sudah ada di codebase
    - Mobile: teks "Export PDF" hidden (`hidden sm:inline`), icon tetap tampil
  </action>
